# 📱 Mobile Application Development – Practical 5

## 📌 Project Overview

This repository contains **Practical 5** of the Mobile Application Development (MAD) course. The project is developed using Android Studio to practice Android application development and understand the structure of an Android project.

## 🎯 Objectives

- To understand the fundamentals of Android application development.
- To learn how to organize an Android Studio project.
- To implement the assigned practical using Android development tools.
- To gain hands-on experience with Gradle and Android project configuration.

## 🛠️ Technologies Used

- **IDE:** Android Studio
- **Programming Language:** Kotlin
- **Build System:** Gradle
- **Platform:** Android

## ✨ Features

- Android application developed as part of MAD Practical 5.
- Structured Android Studio project.
- Gradle-based build and configuration.
- Designed to demonstrate the concepts covered in the practical assignment.

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/nidhitrentiya/24012011188_nidhi_trentiya_pr_5_mad.git
   ```

2. Open Android Studio.
3. Select **Open** and choose the cloned project folder.
4. Wait for Gradle synchronization to complete.
5. Connect an Android device or start an Android emulator.
6. Click the **Run ▶** button to build and execute the application.
